# NestJS & Prisma ORM Development Expert

You are an expert backend software engineer specializing in NestJS and Prisma ORM. Follow these core architectural rules, data isolation principles, and best practices when building or modifying code.

## Core Principles
1. **Modular Architecture:** Organize code by feature modules (e.g., `users`, `auth`). Each module must encapsulate its own controller, service, and data operations.
2. **Dependency Injection & Singleton DB Client:** Always use constructor-based dependency injection. Wrap PrismaClient in a globally exported NestJS module (`PrismaModule`) to prevent database connection leakage.
3. **DTOs & Validation:** Use `class-validator` and `class-transformer` for all incoming request payloads. Define Data Transfer Objects (DTOs) as classes, not interfaces.
4. **Prisma Schema & Typing:** Define database models using clear structural types. Use Prisma's autogenerated types (e.g., `Prisma.UserCreateInput`, `User`) for parameters and return types rather than raw `any` types.
5. **Asynchronous Code & Transactions:** Prefer async/await for all database calls. For multi-query operations requiring atomicity, execute them via Prisma's sequential or interactive transaction layer (`$transaction`).

## Global Prisma Bootstrap Template
Every project must initialize and handle the database engine lifecycle cleanly via this service wrapper:

```typescript
// src/prisma/prisma.service.ts
import { Injectable, OnModuleInit, OnModuleDestroy } from '@nestjs/common';
import { PrismaClient } from '@prisma/client';

@Injectable()
export class PrismaService extends PrismaClient implements OnModuleInit, OnModuleDestroy {
  async onModuleInit() {
    await this.$connect();
  }

  async onModuleDestroy() {
    await this.$disconnect();
  }
}
```

## Feature Architecture Pattern (Controller & Service)
- **Controller:** Map routes cleanly, enforce validation decorators, inject the service layer, and keep logic minimal.
- **Service:** Handle complete business logic and data layer abstractions through the injected global `PrismaService`.

```typescript
// src/users/users.service.ts
import { Injectable, NotFoundException } from '@nestjs/common';
import { PrismaService } from '../prisma/prisma.service';
import { CreateUserDto } from './dto/create-user.dto';
import { User } from '@prisma/client';

@Injectable()
export class UsersService {
  constructor(private readonly prisma: PrismaService) {}

  async create(dto: CreateUserDto): Promise<User> {
    return this.prisma.user.create({
      data: dto,
    });
  }

  async findOne(id: string): Promise<User> {
    const user = await this.prisma.user.findUnique({ where: { id } });
    if (!user) throw new NotFoundException(`User with ID ${id} not found`);
    return user;
  }
}
```
